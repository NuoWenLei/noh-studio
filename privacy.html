Privacy Policy

Last updated November 3, 2026

No One's Headspace Studio ("the studio") is a private tool that its owner, Nuo Wen Lei, uses to upload their own videos to their own YouTube channel. It has no other users.

YouTube API Services

The studio uses YouTube API Services. By using the studio you agree to be bound by the YouTube Terms of Service. Information the studio receives from YouTube is also covered by the Google Privacy Policy (https://policies.google.com/privacy).

Information the studio accesses

When the owner connects their Google account, the studio asks for these YouTube permissions:

  • youtube.upload, to upload videos to the owner's channel;
  • youtube.force-ssl, to add caption files and a thumbnail to those videos, and to read their upload status.

Through the YouTube API Services the studio reads only:

  • the connected channel's name, to show which channel is connected;
  • for each video it uploads, the video's ID, its caption track's ID and its privacy status, to confirm the upload stayed private.

It does not read, change or delete any other videos, comments, playlists, subscribers or analytics, and it does not access any other Google data.

How information is used and stored

  • Sign-in token. The refresh token Google issues is stored only on the owner's own computer, in a file readable only by the owner's account. It is used only to call the YouTube API for the uploads described above.
  • Upload records. For each upload, the studio saves the video ID, the caption track ID, the video's privacy status and a YouTube Studio link in the episode's folder on the owner's computer.
  • No cookies or tracking. The studio does not use cookies, browser storage, analytics or advertising identifiers, and it does not store or read information on users' devices other than the files above on the owner's computer.

Sharing

The studio does not sell, share, transfer or disclose any information from YouTube API Services or Google accounts to any third party. It does not use that information for advertising, and it does not use it to train AI or machine-learning models.

The studio's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Retention and deletion

  • Revoke access at any time from your Google account's security settings: https://security.google.com/settings/security/permissions. Once access is revoked, the stored token stops working.
  • Deleting stored data. The sign-in token and upload records can be deleted from the owner's computer at any time. Ask for deletion by email (below); it is completed within 7 days, and the token is deleted when the YouTube connection is no longer needed.
  • Apart from the sign-in token and the upload records above, the studio does not keep any data received from YouTube API Services. The channel name is shown when needed and is not saved.
