Privacy Policy

No One's Headspace Studio · last updated November 3, 2026

No One's Headspace Studio ("the studio") is a private tool that its owner, Nuo Wen Lei, uses to upload their own videos to their own YouTube channel. It has no other users.

What the studio accesses

When the owner connects their Google account, the studio asks for these YouTube permissions:

  • youtube.upload, to upload videos to the owner's channel;
  • youtube.force-ssl, to add caption files and set details on those uploaded videos.

The studio only uploads videos and captions that the owner made, as private videos, and reads back only what it needs to confirm an upload, such as the video's ID and the channel's name. It does not read, change or delete other content, and it does not access any other Google data.

How data is stored

The sign-in token Google issues is stored only on the owner's own computer, in a file readable only by the owner's account. It is never sent anywhere except to Google's own servers when the studio calls the YouTube API.

Sharing

The studio does not sell, share or transfer any Google user data to anyone. It does not use Google user data for advertising, and it does not use it to train AI or machine-learning models.

Google API Services User Data Policy

The studio's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Its use of YouTube API Services is subject to the YouTube Terms of Service and the Google Privacy Policy.

Removing access

Access can be revoked at any time at myaccount.google.com/permissions. Once access is revoked, the stored token no longer works, and the owner can delete it from their computer.
